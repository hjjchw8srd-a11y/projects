# Image Dataset Builder

Программа собирает изображения по поисковым запросам, удаляет визуальные дубликаты и создаёт структуру датасета для машинного обучения.

## Установка

```bash
python -m venv .venv
```

Windows:

```bash
.venv\Scripts\activate
```

Linux/macOS:

```bash
source .venv/bin/activate
```

Установка зависимостей и самого пакета:

```bash
python -m pip install --upgrade pip
pip install -e .
```

## Запуск

Основной способ:

```bash
python -m image_dataset_builder
```

После установки также доступна команда:

```bash
image-dataset-builder
```

В меню можно:

1. создать новый датасет;
2. разделить проверенную папку `raw` на `train` и `test`;
3. выйти из программы.

Запустить мастер сбора напрямую:

```bash
python -m image_dataset_builder collect
```

Разделить готовый датасет без открытия меню:

```bash
python -m image_dataset_builder split datasets/my_dataset_YYYYMMDD_HHMMSS
```

Для разделения можно указать:

- точную папку конкретного запуска, внутри которой лежат `raw`, `train`, `test` и `.image_dataset_builder.json`;
- родительскую папку, если внутри неё находится только один созданный датасет.

Например, оба варианта допустимы:

```text
datasets/cars_20260802_220307
datasets
```

Если `metadata.csv` открыт в Excel или другом редакторе и Windows блокирует его изменение, файл нужно закрыть и повторить разделение.

## Как проходит сбор

```text
поисковый запрос
→ найденные ссылки
→ скачивание
→ проверка размера и формата
→ преобразование в JPEG
→ проверка dHash
→ сохранение в raw
→ запись metadata.csv
```

Поисковая система может вернуть изображение неправильного класса. Поэтому после сбора папку `raw` нужно проверить вручную и удалить или перенести неподходящие изображения.

При последующем разделении программа автоматически удалит из `metadata.csv` строки о файлах, которых больше нет в `raw`.

## Основные параметры

### Максимальное число найденных ссылок для одного запроса

Это число результатов, которые поисковая система вернёт для одного поискового запроса. Оно не равно числу сохранённых изображений: часть файлов может оказаться недоступной, слишком маленькой или быть дубликатами.

### Безопасный поиск

Фильтрует нежелательный контент:

- `off` — фильтрация выключена;
- `moderate` — умеренная фильтрация, рекомендуемый вариант;
- `on` — строгая фильтрация.

### Паузы между загрузками и запросами

Паузы уменьшают нагрузку на сайты и вероятность получить временную блокировку или ответ `429 Too Many Requests`.

### Период публикации результатов

- `all` — без ограничения;
- `d` — за последний день;
- `w` — за последнюю неделю;
- `m` — за последний месяц;
- `y` — за последний год.

### Качество JPEG

- `1–40` — низкое качество;
- `50–75` — среднее;
- `85–92` — рекомендуемый диапазон;
- `93–100` — высокое качество и заметно больший размер файлов.

По умолчанию используется `92`.

### Режим поиска дубликатов

- `strict` — удаляются только почти точные копии;
- `normal` — рекомендуемый режим;
- `aggressive` — удаляется больше похожих изображений, возможны ложные срабатывания.

### Область проверки дубликатов

- `dataset` — новое изображение сравнивается со всеми изображениями датасета;
- `class` — сравнение выполняется только внутри текущего класса.

Для классификации обычно лучше `dataset`, чтобы одинаковая фотография не попала в разные классы.

### Фильтр лицензии

Фильтр ограничивает поисковую выдачу по указанному типу лицензии. Он не является юридической гарантией права на публикацию изображения или всего датасета. Перед публичным распространением источники и лицензии нужно проверять отдельно.

## Структура результата

```text
my_dataset_YYYYMMDD_HHMMSS/
├── raw/
├── train/
├── test/
├── rejected/
├── metadata.csv
├── dataset_settings.json
├── split.csv
└── .image_dataset_builder.json
```

Временная метка `YYYYMMDD_HHMMSS` добавляется автоматически, чтобы новый запуск не перезаписал предыдущий датасет.

Папка `rejected` предназначена для изображений, которые пользователь убрал из `raw` во время ручной проверки.

`dataset_settings.json` — снимок параметров конкретного запуска. Он нужен для понимания того, как был создан датасет. Абсолютный путь компьютера туда не записывается.

## Безопасные настройки

Пользователь не выбирает низкоуровневые сетевые параметры. Программа автоматически:

- принимает только HTTPS-ссылки;
- использует только порт `443`;
- блокирует локальные и служебные IP-адреса;
- не использует системные `HTTP_PROXY` и `.netrc`;
- требует заголовок `Content-Type: image/*`;
- не принимает анимированные изображения;
- открывает только JPEG, PNG и WEBP;
- удаляет EXIF, GPS и комментарии перед сохранением.

## Использование как Python-модуля

```python
from image_dataset_builder import CollectorConfig, collect_dataset

classes = {
    "bmw": ["BMW M3", "BMW M4"],
    "mercedes": ["Mercedes GLE", "Mercedes AMG"],
}

config = CollectorConfig(
    target_images_per_class=100,
    min_width=300,
    min_height=200,
    duplicate_mode="normal",
)

path = collect_dataset(
    classes=classes,
    output_dir="datasets",
    dataset_name="cars",
    config=config,
)
```

После ручной проверки `raw`:

```python
from image_dataset_builder import split_dataset

split_dataset(
    dataset_root=path,
    train_ratio=0.8,
    random_seed=42,
)
```

## Ограничения

- Качество датасета зависит от поисковых запросов и ручной проверки.
- Поисковый фильтр лицензии не заменяет юридическую проверку.
- При запрете HTTP часть старых источников может быть пропущена.
- Для публичного веб-сервиса потребуются дополнительные ограничения и изоляция.
